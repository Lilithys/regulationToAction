# 数据校准报告 v0.2

完成范围：合并并修复 Person 1—4 的现有合成数据；保留 SME ESG 主线及 IPS/DORA/FRTB 辅助场景；研究日期 2026-09-08。原文件不变，新目录为 [data/calibrated_v0_2](../data/calibrated_v0_2/README.md)。本次“微调”指数据与合同校准，没有进行模型参数训练。

## 修改依据

优先采用项目要求、当前构想、银行场景和原 dataset skill；真实法规决定候选要求应如何定位，bunq 仅用于同业设计参考。原数据中互相矛盾的金额、对象身份与日期按项目银行主场景修复；没有为了维持固定 HIGH/LIMITED 答案而补造审核或运营证据。

## 成本示例与决策边界

10,000 个存量 SME 客户每年审核一次；Lending 52 EUR/hour；人工耗时 low/base/high = 20/30/45 分钟；自动化减少人工处理比例 manual 0%、automated 85%、hybrid 60%。所有人天、价格和处理率均为待审核的合成假设，不是市场报价或 bunq 实测。

| 方案 | 一次建设 EUR | 基准年度运行 EUR | 三年 TCO：low | base | high |
|---|---:|---:|---:|---:|---:|
| Manual | 26,818 | 260,000 | 546,818 | 806,818 | 1,196,818 |
| Automated | 154,436 | 99,000 | 412,436 | 451,436 | 509,936 |
| Hybrid | 79,002 | 134,000 | 377,002 | 481,002 | 637,002 |

基准场景 automated 最低，低单次处理时间场景 hybrid 最低。三年口径为“一次建设 + 三个完整稳态运营年”，不是从今天开始的完整现金流预测，未折现。成本公式及排除项见 [数据字典](../data/calibrated_v0_2/DATA_DICTIONARY.md)。

默认合成机构 `snci_status=false`，研究日已晚于所选 ESG 应用日期；当前候选方案无法使过去的截止日期重新变得可达。改变显式 SNCI 假设会改变所选日期，测试验证了这一条件分支，但实际分类和适用性仍需法律审核。团队交付产能未知，因此即使某成本更低，也保留 `recommended_option_id=null`。

## 验证与复现

运行方式见 [数据入口](../data/calibrated_v0_2/README.md)。本版运行 Person 1 原 strict validator、跨组 validator 和 12 个独立边界测试；结果以 [validation_report.json](../data/calibrated_v0_2/calibration/validation_report.json) 和实际命令输出为准。

检查覆盖：定义 ID 唯一及引用可解析、JSON Pointer、主要余额与分母勾稽、RACI、行动/证据关联、日期和成本算术、原始文件哈希、运行时答案隔离。边界测试覆盖客户数/人日价格变化传播、自动化率越界、未知值、产能不足、SNCI 日期变化、截止日状态、不同输入视图、未收集证据和错误哈希。

没有执行商业平台对比实验、开源检索基线跑分或 LLM 端到端评测。12 个 silver development 案例和 12 个 Python 测试是不同对象，不能把测试通过称为 agent 准确率 100%。

## 后续缺口的具体边界

| 缺口 | 已交付的处理 | 满足什么条件才能升级 |
|---|---|---|
| 官方旧/新全文未保存 | 版本配对登记；`diff_status=not_computed`；来源无伪哈希 | 取得可用官方快照、固定哈希、确认状态后计算并审核差异 |
| 法律适用性与部分现行正文未完整核对 | 全要求 silver、待审核；FRTB 规则禁用 | 合资格审核人签认具体版本、范围、日期与解释 |
| SME 能源数据覆盖率 | missing_facts 中 value 为 null；访谈模板独立 | 得到负责人实际答复或可核对数据；模拟 65% 不能充作答复 |
| 完整当前头寸、VoP standard/API | 缺失清单及 conservative 用例 | 补当前台账、产品/渠道事实及相应证据 |
| 团队产能、损失概率/严重度、收入影响 | 保留 null、不做无依据最终推荐 | 补资源计划与可审查模型/假设；重新运行确定性计算 |
| 控制实操与结案 | 运行证据为空，参考模板待收集 | 真实收集、审核、验证证据；不能只改状态字段 |
| 正式评测成熟度 | 12 个开发用例，禁止训练/测试混用宣传 | 独立人工标注、版本/义务分组留出、冻结协议与来源 |

因此，本轮完成的是可复现、边界明确的校准交付；当前仍是合成原型，不是已审定生产数据。官方 PDF 保存受浏览器自动审批限制的经过和保留缺口，单独记录在 [来源审计](source_audit.md)。
